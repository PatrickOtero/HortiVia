# Captura de screenshots

Esta pasta foi reservada para os prints reais usados na apresentação pública do HortiVia.

## Arquivos esperados

- `home.png`
- `search.png`
- `filters.png`
- `product-detail.png`
- `product-tips.png`
- `articles.png`
- `article-detail.png`
- `preferences.png`

## Como usar esta pasta

- adicione apenas capturas reais do app em execução
- mantenha os nomes de arquivo desta lista para facilitar o uso em README, portfólio e LinkedIn
- prefira telas de produto e conteúdo, não telas de acesso ou áreas internas
- revise dados pessoais visíveis antes de salvar os prints
